## Changes

- **Fast recall by default.** Omitted `recall_level` uses `search.default_recall_level`, which defaults to `fast`. Explicit request modes take precedence. Fast, Normal and Deep provide complete-context ceilings of 8,000, 16,000 and 24,000 tokens. Direct, batch and planned recall share the setting; current integration archives select Fast explicitly by default.
- **Native owner-local BM25 recall.** PostgreSQL full-text matching combines field-weighted BM25 with cover density. Migration 0040 derives the lexical statistics from existing indexed text without model calls. Source eligibility, provenance and complete supported context remain enforced; L2 consolidation target lookup retains its existing FTS policy.
- **Shared recall controls.** All three presets support the same lexical ranking, partial-match gate, adjacent user context, causal graph and source-body policies. Normal and Deep share optional reranking while retaining separate candidate, traversal, context and deadline limits. Fast skips model reranking.
- **English and Simplified Chinese documentation.** Matching setup, API, integration, configuration, operations and technical guides use English by default, with reciprocal language navigation. Existing English links and the Japanese overview remain available.
- **Recorded LME-500 result at 8k.** The published 8,000-token run scored 476/500 (95.2%), with 7,989.54 mean saved context tokens. Its mean context was 29.8% smaller than the completed 18k Normal FTS comparison (478/500, 95.6%). This is recorded evaluation evidence, not a new release-time benchmark. [Method and comparison limits](../benchmarks.md#1-longmemeval-s-at-8k-and-18k).
- **Updated client archives.** This release supplies OpenClaw 0.0.3, MCP 0.0.2 and DeepSeek Harness 0.0.3 archives with three-mode support. The npm registry versions remain OpenClaw/DSH 0.0.2 and MCP 0.0.1; use the release archives for the new client behavior.

## Upgrade

Stop API and worker processes, apply migrations with the privileged migration credential, then restart them with the same configuration. Migration `0040_bm25.sql` backfills stored lexical fields and blocks `search_units` writes during that transaction. Existing facts, embeddings and completed indexes are preserved. [Deployment](../../deploy/README.md) and [migration details](../operations.md#3-bootstrap-and-credentials).

For custom YAML, move `lexical_ranking`, `partial_match_gate`, `adjacent_user_context`, `adjacent_user_context_max_chars`, `causal_graph` and `fact_source_bodies` from mode presets to `search`. Remove Fast's former `rerank_candidates` and `rerank_min_score`. Normal defaults to 128 fused candidates, so keep its result and rerank caps within that limit or raise it explicitly. Select `search.default_recall_level: normal` or `deep` if that is the desired API default. [Configuration](../../configs/README.md).

## Verification

The default suite passed 2,099 tests and skipped 674 checks whose optional infrastructure was not enabled in that run. Separately, 139 selected PostgreSQL integration cases covered BM25 projection/backfill, owner isolation and recall graph/temporal paths, and 36 checks ran in the existing Chrome browser. The first database run had 24 setup failures because its base database lacked migrations; initialization and a 26-case rerun resolved them. Integration package suites passed 119 tests; packaged MCP was launched through its documented archive command and consumed cited Fast, Normal and Deep results.

An isolated PostgreSQL 18 deployment with two API and two worker replicas completed real-provider indexing, persisted supported L2 Insights, all three recall modes and omitted-mode Fast selection, Profile generation and zero-call unchanged reuse, HTML/PDF/PNG resource indexing and joint cited recall. Ten concurrent reads were served by both API replicas. Preflight validated DeepSeek Flash text and vision, and finite 1,024-dimensional Qwen embeddings. This synthetic run does not establish a new benchmark score, full production recovery or physical multi-host availability.

Native ARM64 and emulated AMD64 image checks reported 0.2.1, the Fast default and 8k/16k/24k limits, and matched all 144 packaged runtime files. Public registry identities, downloadable artifact checksums, actual model usage and remaining deployment limits are recorded in the attached sanitized release evidence. Live OpenClaw and DSH host installation was not repeated.
