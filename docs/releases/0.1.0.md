## Overview

Higher recorded accuracy with low-cost Flash models and smaller LongMemEval context. This release pairs the recorded benchmark milestone with source-evidence selection and context-formatting improvements; benchmark evidence and evaluated commits live in [OAMB](https://github.com/rocke2020/open-agent-memory-benchmark).

## Changes

- **LongMemEval S: 95.2% (476/500), compared with Hindsight's recorded 94.6% (473/500).** MiniMax M3.1 Flash supplies both answers and judgments. At an 18,000-token evaluation cap, 497 saved contexts average 11,373.58 tokens versus 43,124.55 in the Hindsight artifact, a **73.63% reduction**. Three disputed-gold cases remain incorrect in the unchanged 500-question denominator.
- **BEAM-10M: 61.56%, compared with Hindsight saved-context replay at 52.16%.** The recorded 200-question evaluation spans ten complete histories and uses DeepSeek Flash answering and judging. Selected answers retain their high/max reasoning settings. OAM used 17.43% more answer context on this workload. Different model pipelines and scoring methods limit causal comparisons; see [benchmark methodology, pricing and per-question evidence](../benchmarks.md).
- **Low-cost Flash-model pipelines.** MiniMax M3.1 Flash and DeepSeek Flash demonstrate the recorded results without requiring a flagship answer model. Vendor list prices are documented separately from actual campaign bills; smaller saved LME contexts do not establish a total cost ratio.
- Improve source-evidence selection: retain the leading eligible lexical conversation original, keep source-discovery and reply-witness budgets independent of final result caps, reuse loaded source bodies, and rank eligible source-local user originals with deterministic cosine-distance ties. Normal whole-query lexical retrieval uses document-length normalization outside fallback.
- Share repeated complete temporal metadata through compact context-local references only when the complete rendered context is smaller. Evidence bodies, citations and structured time metadata remain intact.
- Lower the default normal recall context cap from 32,768 to **24,000 tokens**; fast remains **18,000**. The latest LME campaign's 18,000-token normal cap is an evaluation override.
- Add opt-in late fast scoring with an optional provider-specific score floor and explicit omission/degradation diagnostics. Default fast recall still makes no reranking call. Add experimental fast source-body policies `ranked`, `ranked_deduplicated` and `assistant_deduplicated`; `required` remains the default. These experimental policies have no general accuracy guarantee.
- Put performance proof near the top of the English, Chinese and Japanese READMEs and provide a visible Docker-to-first-cited-memory path. Synchronize the Chinese configuration guide with the implemented controls.

## Upgrade

From v0.0.3, reuse existing indexes; these retrieval-only changes require no new schema migration or reindexing. Restart API processes after upgrading the image or recall configuration. Apply previously required schema migrations when upgrading from an older version.

Operators inheriting the canonical normal cap now receive 24,000 tokens. An explicit custom `search.normal.context_max_tokens` retains its configured value; choose a supported cap that fits the host's complete model input. Returned `context_tokens` count saved formatted context with `o200k_base`, not provider-billed tokens.

Fast scoring remains disabled unless both `models.reranker` and a positive `search.fast.rerank_candidates` are configured. A finite `search.fast.rerank_min_score` additionally requires both controls; scores and floors are provider-specific. Keep `search.fast.fact_source_bodies: required` for existing full-source behavior. Validate experimental policies against your actual evidence and workload before adoption; see the [configuration guide](../../configs/README.md#6-optional-fast-scoring).

OpenClaw remains independently versioned at 0.0.2; MCP and DSH remain at 0.0.1. Their package code is unchanged and existing versions are reused.

## Verification and publication

Source-candidate checks on November 18, 2026: **1,935 pytest cases passed and 624 skipped**. Ruff check and format check passed; Mypy reported no issues in 310 source files. The default run did not enable isolated database, browser or external-runtime acceptance. The unchanged OpenClaw, MCP and DSH suites passed **67, 28 and 11 tests**, respectively, with zero failures.

Python source distribution and wheel builds passed; package inspection confirmed v0.1.0 metadata, the CLI entry point, canonical configuration, migrations and Inspector assets. Both Linux ARM64 and AMD64 candidate images built and passed installed CLI/version and packaged configuration/asset checks; ARM64 ran natively and AMD64 under emulation. The corrected three-module OAMB saved-evidence command passed 30 tests without generating new model output.

Isolated candidate acceptance passed through the public HTTP API with DeepSeek Flash thinking disabled and local 1024-dimensional embeddings: retained L0, source-supported L1/L2, cited fast/normal recall, unchanged zero-call Profile refresh, HTML/PDF/PNG Resources, joint recall and ten reads across two API replicas. Independent checks matched citations to retained originals and recomputed exact context tokens. Administrator listing returned the expected user, a future filter returned HTTP 200 with zero results, and a user key was denied administrator listing. The Inspector connected in existing Chrome, loaded sources and data with all required assets returning 200, and logged no console errors. A fresh MCP process returned cited live evidence and shut down cleanly. API shutdown completed, and all ten durable work attempts finished successfully before task workers stopped.

The acceptance run made 14 generation calls, using 14,174 input and 1,685 output tokens (15,859 total), with no failed attempts. Embedding tokens are excluded. Separate reasoning usage was not reported; thinking was disabled. These measurements are a bounded functional acceptance run, not a new benchmark or a reconciled bill.

Public-download checks follow publication and are reported with immutable artifact identities in the GitHub Release evidence. This local simulation does not establish physical multi-host recovery, native AMD64 host behavior, or fresh OpenClaw/DSH host acceptance; unchanged integration package tests and runtime archive contents were checked separately.
