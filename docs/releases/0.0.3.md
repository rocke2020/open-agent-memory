## Changes

- Present LME-500 results as **93.2% (466/500)** with MiniMax M3.1 Flash native-adaptive answers and DeepSeek Flash high-effort judging, alongside **92.6% (463/500)** for DeepSeek Flash max-effort answers on identical saved OAM contexts. Link the paired OAMB evidence and synchronize the English, Chinese and Japanese introductions. These are recorded L1/fast-recall results, not fresh measurements of this release image.
- Rename each search tier's `graph` configuration key to `entity_semantic_graph`, making entity/alias expansion and optional semantic-link expansion explicit. Direct dense semantic retrieval and lexical entity-name matching remain independent; `causal_graph` remains a separate control.
- Add a copyable retain → readiness → cited-recall onboarding guide, clarify long-term-memory eligibility, and improve configuration explanations and multilingual README examples.

## Upgrade

In custom YAML, replace `search.fast.graph` with `search.fast.entity_semantic_graph` and `search.normal.graph` with `search.normal.entity_semantic_graph`. Retain the selected `off`, `light` or `full` value. The HTTP `fast_graph` request override is unchanged. Canonical configuration uses the new names; old tier keys are rejected by the strict configuration schema. No database migration or reindexing is needed solely for this rename. Apply previously required migrations when upgrading from an older schema.

OpenClaw remains independently versioned at 0.0.2; MCP and DSH remain at 0.0.1. No integration package is republished for this product version.
