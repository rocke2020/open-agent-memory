# Open Agent Memory 0.0.1

## Changes

This initial release introduces the self-hosted memory engine and its HTTP API:

- Retain original interaction evidence, extract source-backed learned memory and synthesize supported Insights.
- Ingest text, HTML, PDF and image Resources as separate searchable evidence.
- Recall learned memory and Resources together with citations through fast and normal modes.
- Refresh a stored User Profile explicitly, using eligible memory and exact Profile Data; reuse unchanged inputs without generation.
- Manage source revisions, deletion, individual memory removal, recorded diagnostics and portable exports.
- Browse and manage content through the bundled Memory Inspector.
- Run stateless APIs and durable workers over PostgreSQL/pgvector, with container deployment and OpenClaw/DSH integrations.

## Scope and limitations

These notes describe the source at Git tag `v0.0.1`. They were reconstructed from that tag's README; they do not certify a new deployment, rerun benchmarks or establish artifact availability. The initial release predates the documentation-review gate and has no retrospective review fingerprint. Later product changes and independently versioned plugin updates belong to their own releases.

The initial release excludes a Python SDK, hosted service, database high availability and multi-region operation. Local replica simulations do not establish physical multi-host resilience. Historical benchmark results are development-snapshot evidence rather than fresh matched comparisons.
