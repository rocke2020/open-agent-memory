# Synthetic bilingual reports

These English and Chinese HTML, text PDF, scanned PDF, and PNG reports describe the same fictional laboratory values. `SYN-001` is a synthetic subject code; the files contain no personal or clinical data from a real person. The scanned PDFs intentionally have no text layer so tests can exercise page rendering and document vision.

The additional English and Chinese allergy reports contain 27 fictional allergen rows across three pages each. They contain only native PDF text objects, so every page exercises text extraction and page citations without document vision. Values are synthetic and carry no clinical interpretation.

`en-mixed-native-image.pdf` is a separate synthetic fixture (SHA-256 `9c298ebe62fc00b161334ad9d580793f8cdbf7b47d0d93942ee5e2e71fd9ac44`). Its native text says `Sodium: 140 mmol/L`, while an embedded report image contains `Glucose 92 mg/dL` and `Potassium 4.2 mmol/L`. The public retain-to-recall test verifies that the native and vision passages both retain physical-page citations. This supplied file is not regenerated by `generate.py`.

Regenerate with `uv run --with reportlab python conformance/fixtures/medical/bilingual/generate.py --font /path/to/NotoSansSC.ttf`. The font is a local build input and is not included here. The generated PDFs embed only the needed font subset. The reports were generated with [Noto Sans SC](https://github.com/notofonts/noto-cjk), whose [SIL Open Font License](https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE) permits embedding; `OFL.txt` records the accompanying license notice.
